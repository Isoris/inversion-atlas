Het-skeleton seed discovery (Cluster 1 Path B)
Seeds are built from the het signal: per-window K-means → het_detect_candidate_band → het_track_skeleton → hom_anchor_to_het → cramers_v_merge — no band-quality gate, no V-walker. The same Cluster 2 + 3 tail (breadth voting + regime refinement + topology) then runs on those seeds. Use the arrow keys to navigate seeds (←/→), band combos (↑/↓), and chromosomes (c); press g for the genome-scope panels.
For the V-walker chromosome-wide sweep go to haplotype_regimes; for the curated candidate list go to candidate_regimes.

Each chip in the seeds strip below is one het-skeleton seed the pipeline discovered — a window range where the het backbone walks consistently enough to suggest a haplotype regime. Use ←/→ or click a chip to set the focal seed; the 4 panels below repaint to show how that seed's voter projects across the chromosome.
Action menu:
  • ★ promote seed — turn the focal seed into a tracked candidate inversion.
  • ★★ promote all — promote every discovered seed as a candidate in one shot.
  • ↻ auto-merge V — walk adjacent seeds and auto-promote consecutive-MERGE chains.
  • export catalogue… — serialize the in-memory pipeline result to a regime-catalogue JSON.
