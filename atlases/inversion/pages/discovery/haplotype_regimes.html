Each chip in the seeds strip below is one Stage 1 seed the pipeline discovered — a window range where the K-band labels shift consistently enough to suggest a haplotype regime boundary. Use ←/→ or click a chip to set the focal seed; the 4 panels below repaint to show how that seed's voter projects across the chromosome.
Top-left panel (chrom · target-band lanes): for the focal seed's voter (a chosen subset of bands), where does each target window classify? Solid bands = clean projection; scattered = noisy. Bottom-left (chrom · PC1 lines): the raw per-sample PC1 with the voter samples highlighted in gold. Genome-scope panels (right column) only appear after Show genome view + Compute genome view.
Action menu:
  • ★ promote seed — turn the focal seed into a tracked candidate inversion (appears in local_pca_dosage's candidate carousel and is persisted to localStorage).
  • ↻ auto-merge V — walk every adjacent seed pair and auto-promote consecutive-MERGE chains as candidates (Cramér's V on Hungarian-aligned labels).
  • ↻ auto-merge Vmacro — same, but bounded WITHIN each Stage 3 macrostripe so the walker never crosses locus boundaries.
  • export catalogue… — serialize the in-memory pipeline result (seeds + loci + regimes + topology) to a regime-catalogue JSON for archival / downstream tools.
  • switch view → long-range regimes — replace the seeds strip with the refined regime blocs (Cluster 3 output) when you want the consolidated picture instead of raw seed-by-seed inspection.
Don't see anything useful? Try a different seed mode (long-range / short-range / het-skeleton) in the top-left pill group, then click run pipeline again. Each mode uses a different seed-discovery strategy.
