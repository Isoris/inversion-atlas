what is this panel? (click)
The big plot above is the tracked-samples PCA scatter. It pins a set of samples to the same canvas as the cohort cloud, so you can watch them move as you scrub the cursor through windows.
  • Click a point to add/remove it from the tracked set
  • Shift+drag to lasso a region → creates a manual group lasso_N
  • Lasso toggle (in ▾ settings): plain drag becomes a tracked-samples lasso instead
  • Trails (▾ settings): connect each tracked sample's position back N windows
  • K-band buttons below: pre-pick samples from one K-means cluster only
  • Auto-pick: spread the picks radially across PC1/PC2 so all bands are represented
Colour mode is controlled from the ▾ settings (family / ancestry / het / dosage / θπ / GHSL / manual). Shift+drag creates a manual group but no longer hijacks the colour mode — you keep whatever colouring you picked.
